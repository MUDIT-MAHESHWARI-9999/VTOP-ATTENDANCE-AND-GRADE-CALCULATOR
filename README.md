# VTOP Attendance & Grade Predictor

A CLI-based utility tool built for VIT students to manage course attendance margins and estimate target FAT marks for desired letter grades.

## Key Features
- **Attendance Margin Calculator:** Calculate safe bunks or required recovery classes to maintain 75% or custom targets.
- **FAT Grade Estimator:** Convert internal scores ($CAT 1, CAT 2, DA$) into exact required scores on the 100-mark FAT paper.
- **Persistent Data:** Save and update course progress locally in JSON format.
- **Unit Tested Engine:** Core calculations backed by automated unit tests.
